# 💻 Terminal-simulado

Terminal-simulado é um shell interativo desenvolvido em C++, criado para fins educacionais. O projeto simula o funcionamento de um terminal de sistema operacional, permitindo a execução de comandos personalizados em um ambiente 

---
## ⚙️ Funcionalidades

- 🔹 Sistema de comandos dinâmico (`help`, `info`, `ver`, `clear`, `user`, `exit`)
- 🔹 Interface de terminal interativa
- 🔹 Simulação de boot do sistema
- 🔹 Gerenciamento simples de usuário
- 🔹 Estrutura baseada em `std::map` e `std::function`
- 🔹 Suporte à expansão de novos comandos

---

## 🚀 Como executar

### 📦 Requisitos

- Compilador C++ (GCC, MinGW ou Clang)
- Sistema operacional Windows ou Linux
- Python 

---

### 🔨 Compilação

```bash
g++ main.cpp -o terminal
